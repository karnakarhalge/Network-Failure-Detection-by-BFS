Design & Analysis of Algorithms — Technical Reference

1. Graph Formalization

A computer network is modeled as an undirected, unweighted graph $G = (V, E)$, where $V$ represents router nodes and $E$ represents communication links. Uniform weight $w(e) = 1$ is assumed across all links, transforming the minimum latency routing problem directly into the minimum hop-count problem.

Theorem: BFS Shortest Path Optimality

In an unweighted graph, Breadth-First Search discovers vertices in non-decreasing order of their shortest-path distance $\delta(s, v)$ from the source:

∀ v ∈ V,   dist[v] = δ(s, v)

Because a FIFO queue is used, vertices at distance $k$ are strictly dequeued before any vertices at distance $k+1$. Therefore, the first time vertex $v$ is visited via edge $(u, v)$, the discovered path is guaranteed to have the minimum possible hop count.

2. Complexity Derivations

Time Complexity: O(V + E)
  • Each vertex enters and leaves the FIFO queue at most once: $\mathcal{O}(V)$.
  • Each incident link is scanned once per endpoint: $\sum_{u \in V} \text{deg}(u) = 2E$, giving $\mathcal{O}(E)$.
  • Total runtime is linear with respect to graph size: $\mathcal{O}(V + E)$.
Articulation Point (SPOF): O(V(V + E))
  • Brute-force vertex removal tests every router $v \in V$ ($|V|$ iterations).
  • For each candidate, a full BFS connectivity check runs in $\mathcal{O}(V + E)$ on the induced subgraph $G[V \setminus \{v\}]$.
  • Total runtime: $|V| \times \mathcal{O}(V + E) = \mathcal{O}(V^2 + VE)$.

3. BFS vs. DFS in Network Reliability

Feature Breadth-First Search (BFS) Depth-First Search (DFS)
Data Structure FIFO Queue (level-by-level) LIFO Stack / Recursion
Shortest Path Guaranteed minimum hop count No hop guarantee (explores deep)
Memory Profile Proportional to graph width $O(W)$ Proportional to graph depth $O(D)$
Edge Classification Tree edges and Cross edges Tree, Back, Forward, Cross edges

4. Key Viva Questions & Answers

Q: Why does standard BFS fail on weighted graphs?

A: BFS dequeues vertices purely by hop count, not cumulative link weights. If a 2-hop path has a lower total latency than a 1-hop link, BFS will choose the 1-hop path. Weighted networks require Dijkstra's Algorithm with a priority queue ($\mathcal{O}((V + E) \log V)$).

Q: Can articulation points be found faster than $\mathcal{O}(V(V + E))$?

A: Yes. Tarjan's algorithm uses DFS back-edges and low-link values (`low[u]`) to discover all articulation points and bridges in linear time $\mathcal{O}(V + E)$. The BFS removal method is used here to demonstrate empirical partition detection and multi-fault resiliency.
